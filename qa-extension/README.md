# qa-extension

Automates loading, testing, debugging, and fixing a Firefox browser extension in a loop until all tests pass.

## Install

```bash
claude plugin marketplace add joliehuangdev/firefox-prototype-plugins
claude plugin install qa-extension@firefox-prototype-plugins
```

## Usage

Invoke with `/qa-extension` or describe your extension testing task and Claude will activate it automatically.

## Skills

- `qa-extension` — full test → debug → fix → repeat workflow for Firefox extensions
